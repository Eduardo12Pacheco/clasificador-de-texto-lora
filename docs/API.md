# API guide

`stc serve` starts the FastAPI application on the loopback interface. The
service loads the shipped ONNX bundle once at startup and exposes the same
calibrated classifier as `stc predict`. It never downloads models or data.

## Start the service

```bash
stc serve                       # 127.0.0.1 and STC_API_PORT (19080 by default)
stc serve --host 127.0.0.1 --port 8000 --model stc-es-intent
```

Binding a non-loopback address prints a warning: the service has no
authentication and is intended for local use.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/healthz` | Liveness plus `model_loaded` |
| `GET` | `/v1/model` | Manifest identity, calibration and baseline availability |
| `GET` | `/v1/labels` | The 60 intents and 18 scenarios |
| `POST` | `/v1/predict` | Calibrated top-k predictions for 1–64 texts |
| `GET` | `/` and `/static/*` | Bundled web UI (no CDN, no third-party requests) |

### Predict

```bash
curl -s -X POST http://127.0.0.1:8000/v1/predict \
  -H 'content-type: application/json' \
  -d '{"texts": ["apaga la luz", "despiértame a las cinco"], "top_k": 2, "model": "default"}'
```

```json
{
  "schema_version": 1,
  "model": {
    "id": "stc-es-intent",
    "kind": "onnx-seqcls",
    "version": "0.1.0",
    "quantization": "fp32",
    "temperature": 1.0,
    "review_threshold": 0.95
  },
  "predictions": [
    {
      "index": 0,
      "intent": "iot_hue_lightoff",
      "scenario": "iot",
      "confidence": 0.93,
      "needs_review": false,
      "top_k": [
        {"intent": "iot_hue_lightoff", "scenario": "iot", "probability": 0.93},
        {"intent": "iot_hue_lightdim", "scenario": "iot", "probability": 0.04}
      ]
    }
  ],
  "latency_ms": 18.4
}
```

Input order is preserved: `predictions[i].index == i`. `model` may be
`"baseline"` when the installed bundle carries a baseline; otherwise the API
returns `404`.

## Limits

- `texts`: 1–64 items, each 1–512 characters after stripping; blank texts are
  rejected.
- `top_k`: 1–10, never larger than the label space.
- `model`: `"default"` or `"baseline"`.
- The request body must not contain unknown fields (`extra="forbid"`).

## Errors

Every error response is RFC 7807 `application/problem+json`:

```json
{
  "type": "about:blank",
  "title": "invalid request",
  "status": 422,
  "detail": "request validation failed: body.texts"
}
```

| Status | Cause |
|---|---|
| `404` | `model="baseline"` was requested but no baseline is installed |
| `422` | Bound or schema violation |
| `500` | Unexpected failure (generic detail; no input text) |
| `503` | Model unavailable, unsafe artifact or offline refusal |

## Security and privacy

- The server binds `127.0.0.1` by default; `STC_API_HOST` or `--host` changes it
  and a non-loopback value logs a warning.
- Responses carry `Content-Security-Policy: default-src 'self'`,
  `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`.
- Every response echoes or generates `X-Request-ID`.
- Access logs contain method, path, status, duration and `n_texts`; the input
  text is never logged.
- Model bundles are verified against their manifest sha256 before use.
